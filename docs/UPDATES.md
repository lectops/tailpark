# In-app updates

Open **Settings → Updates → Check for updates** to check the latest stable release from `lectops/tailpark`. Tailpark shows its version and release notes, downloads with progress, and offers **Install update**. Android may first ask you to allow Tailpark to install packages; return to Updates and tap Install again after granting that permission. These are replacement installs, preserving the existing package's login and settings.

Checks also run through WorkManager approximately every six hours when networking and Android background scheduling permit. Opening Updates shows the saved offer even when automatic updates are off. Manual checks are limited to one per minute; GitHub rate-limit responses persist a backoff of at least six hours. Offline and invalid-release failures leave the currently installed app running and allow retry.

**Automatically update while parked** is off by default. When enabled, an existing helper heartbeat can enqueue an update attempt at most once per 15 minutes. Checks still obey the six-hour network-check limit. An attempt downloads only after a helper observation at most 7.5 seconds old confirms ACC off, screen off and the parked phase. Unknown or stale vehicle readings, helper errors, and a pending or completed parked idle timeout defer automatic installation.

Downloaded bytes must match the release's `SHA256.txt`, identify the exact installed package, carry the installed app's current signing certificate set, match the offered upstream version and BYD revision, and have a strictly newer Android version code. Version comparisons handle numeric BYD revisions and the upstream build suffix in Android's version name. Drafts, prereleases, odd upstream development versions, ambiguous/missing assets, and assets outside this repository are rejected. A checksum alone is not sufficient trust: the installed signing certificate is required. Builds signed with your own key cannot automatically install the public release signer.

For unattended installation, Tailpark uses only the already-authorized local debugging key. It never creates a new key or opens a pairing prompt in this path. A fixed shell entrypoint receives the APK over a single-use random-token-authenticated loopback stream and stages it in the shell's private runtime directory. It independently repeats APK checksum, package, signer and version checks. The app then rechecks persisted opt-in and fresh helper state before authorizing commit; disabling automatic updates prevents a pending commit. The shell rereads the OEM ACC and vendor screen state immediately before running the fixed `pm install -r` command. Stopping parked operation or reaching its idle timeout also blocks commit. Once the install transaction is authorized, a later preference change cannot reliably cancel it.

If the local debugging connection, OEM reads, or shell installation are unavailable or refused, the verified download is retained. Updates then offers Android's ordinary install confirmation the next time you open it; no background confirmation screen is launched. Firmware denial is remembered for that release to avoid repeated installation attempts. The normal package-replaced recovery receiver and watchdog reload the new APK using the preserved connection intent.

The host regression suite covers version/build normalization, release metadata and asset restrictions, checksum ambiguity, wrong packages/signers/versions, bounded and incomplete local transfers, wrong nonces, cancellation before commit, stale/unknown parked observations, ACC changes during final validation, stop/expiry gating, and denied installation fallback. No vehicle was contacted during implementation.

Vehicle validation remains required: install a same-key update on DiLink/Android 10, confirm login and settings survive and VPN/helper return, test shell permission denial and manual confirmation, toggle opt-in while downloading, and change ACC/screen state between download and commit. Automatic updates can briefly interrupt remote work. A successful host build does not prove firmware allows unattended installation.
